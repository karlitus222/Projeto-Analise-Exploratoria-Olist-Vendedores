## Antes de trocar o CSV

A base da demonstração tem 41 colunas. O pipeline da raiz produz outro formato, com 46 colunas. Leia a seção de integração do guia de continuidade antes de substituir o arquivo: renomear campos, sozinho, não garante que as métricas mantenham o mesmo significado.

O histórico de verificações é cronológico e inclui versões antigas. Para o comportamento atual, use o README do painel e as seções finais desse histórico.
